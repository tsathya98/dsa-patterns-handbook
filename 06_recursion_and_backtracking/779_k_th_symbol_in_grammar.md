# LeetCode 779: K-th Symbol in Grammar

> **Difficulty:** Medium | **Pattern:** Divide and Conquer / Binary Reflection  
> **Source Code:** [`779_k_th_symbol_in_grammar.py`](./779_k_th_symbol_in_grammar.py)

## The problem

Build a table of $n$ rows (1-indexed). Row 1 is `0`. Each subsequent row is generated by replacing every `0` with `01`, and every `1` with `10`. Given $n$ and $k$, return the $k$-th symbol in row $n$.

## Why the naive way fails

Row $n$ has $2^{n-1}$ characters. For $n = 30$, generating the string requires $2^{29} \approx 5.36 \times 10^8$ characters, which triggers an Out of Memory (OOM) error or Time Limit Exceeded (TLE) immediately.

## The core trick

Inspect how each row is generated:
```text
Row 1: 0
Row 2: 0 1
Row 3: 0 1 | 1 0
Row 4: 0 1 1 0 | 1 0 0 1
```

Notice two mathematical properties:
1. Row $n$ has $2^{n-1}$ elements. The midpoint is at $mid = 2^{n-2}$.
2. The **left half** (`k <= mid`) is a copy of row $n - 1$:  
   `kthGrammar(n, k) = kthGrammar(n - 1, k)`.
3. The **right half** (`k > mid`) is the bitwise complement (`1 - x`) of row $n - 1$ at relative index $k - mid$:  
   `kthGrammar(n, k) = 1 - kthGrammar(n - 1, k - mid)`.

### Algorithm steps:
* **1. Check base case:** If `n == 1`, return `0` (the root row is defined as `0`).
* **2. Compute midpoint:** Calculate the midpoint of row `n`: `mid = 2 ** (n - 2)`.
* **3. Branch by half:**
  * If `k <= mid`: target sits in the left half, identical to parent row; return `kthGrammar(n - 1, k)`.
  * If `k > mid`: target sits in the right half, inverted relative to parent; return `1 - kthGrammar(n - 1, k - mid)`.
* **4. Terminate:** Return the unwound bit value.

## Step-by-step trace

Find $n = 4, k = 5$:
- $n = 4, mid = 2^2 = 4$. Since $k = 5 > 4$ (right half):  
  `ans = 1 - kthGrammar(3, 5 - 4) = 1 - kthGrammar(3, 1)`.
- $n = 3, mid = 2^1 = 2$. Since $k = 1 \le 2$ (left half):  
  `kthGrammar(3, 1) = kthGrammar(2, 1)`.
- $n = 2, mid = 2^0 = 1$. Since $k = 1 \le 1$ (left half):  
  `kthGrammar(2, 1) = kthGrammar(1, 1) = 0`.
- Unwinding back: `ans = 1 - 0 = 1`.

<summary>Spoiler: Solution Code</summary>

```python
class Solution:
    def kthGrammar(self, n: int, k: int) -> int:
        if n == 1 and k == 1:
            return 0

        mid = 2 ** (n - 2)

        if k <= mid:
            return self.kthGrammar(n - 1, k)
        else:
            return 1 - self.kthGrammar(n - 1, k - mid)
```

### Alternative O(1) Bit Observation
Because each step to the right flips a bit, the final value is equivalent to the parity of 1s in the binary representation of `k - 1`:
```python
class Solution:
    def kthGrammar(self, n: int, k: int) -> int:
        return (k - 1).bit_count() % 2
```

## Traps to watch for

- **1-indexed $k$ vs 0-indexed powers of 2:** Ensure $mid = 2^{n - 2}$ corresponds correctly to the half-length of row $n$ ($2^{n - 1} / 2$).

## Complexity

- **Time Complexity:** $\mathcal{O}(n)$ recursive calls (each call reduces $n$ by 1). $\mathcal{O}(1)$ with the bit trick.
- **Space Complexity:** $\mathcal{O}(n)$ stack frames.
