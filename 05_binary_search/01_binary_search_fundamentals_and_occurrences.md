# Binary search fundamentals and occurrence boundaries> **Course reference:** CodeKerdos DSA, Class 8  > **Core concepts:** Search space halving, midpoint calculation, first and last occurrence boundaries, occurrence count, floor, and ceil.## 1. Why binary search worksEvery binary search problem has two parts:1. **Target ($K$):** The value or boundary condition you want to find.2. **Search space $[lo, hi]$:** The range of candidate indices still in play.When an array is sorted, checking the midpoint `mid = lo + (hi - lo) // 2` splits the remaining candidates in half. Each comparison eliminates half of the remaining search space:$$\text{Search space after } k \text{ steps} = \frac{N}{2^k}$$Setting $\frac{N}{2^k} = 1 \implies k = \log_2 N$.For $N = 1,000,000$, binary search finishes in at most $20$ comparisons.```textIndices:  0    1    2    3    4    5    6Array:  [ 2 ,  5 ,  8 , 12 , 16 , 23 , 38 ]   Target = 23          ▲              ▲              ▲         lo             mid            hi1. arr[mid] = 12 < 23 -> Target must be to the right -> lo = mid + 1```### Algorithm steps:* **1. Define search bounds:** Set `lo = 0` and `hi = len(arr) - 1`.* **2. Calculate midpoint safely:** While `lo <= hi`, compute `mid = lo + (hi - lo) // 2` to avoid 32-bit integer overflow.* **3. Compare with target ($k$):**  * `arr[mid] == k`: Exact match found! Return `mid` (or record `ans = mid` and steer if finding first/last occurrence).  * `arr[mid] < k`: Target must lie in the right half; narrow interval with `lo = mid + 1`.  * `arr[mid] > k`: Target must lie in the left half; narrow interval with `hi = mid - 1`.* **4. Termination:** If `lo > hi`, the interval is exhausted and target is not in array; return `-1`.```playthrough{  "algorithm": "binary_search",  "initial": [2, 5, 8, 12, 16, 23, 38],  "target": 23}``````pythondef binary_search(arr: list[int], k: int) -> int:    lo, hi = 0, len(arr) - 1    while lo <= hi:        mid = lo + (hi - lo) // 2        if arr[mid] == k:            return mid        elif arr[mid] < k:            lo = mid + 1        else:            hi = mid - 1    return -1```## 2. First and last occurrence in arrays with duplicates (LC 34)When `arr` contains duplicates, standard binary search stops at whichever copy of `k` it hits first, which might sit in the middle of a run of duplicates:```textarr = [ 2 , 4 , 10 , 10 , 10 , 18 , 20 ],  k = 10              ▲    ▲    ▲            First       Last```### First occurrence invariant* When `arr[mid] == k`, record `ans = mid` as the best candidate so far, then keep searching left by setting `hi = mid - 1`.### Last occurrence invariant* When `arr[mid] == k`, record `ans = mid` as the best candidate so far, then keep searching right by setting `lo = mid + 1`.```pythondef find_first_occurrence(arr: list[int], k: int) -> int:    lo, hi = 0, len(arr) - 1    ans = -1    while lo <= hi:        mid = lo + (hi - lo) // 2        if arr[mid] == k:            ans = mid            hi = mid - 1  # Keep searching left for an earlier occurrence        elif arr[mid] < k:            lo = mid + 1        else:            hi = mid - 1    return ansdef find_last_occurrence(arr: list[int], k: int) -> int:    lo, hi = 0, len(arr) - 1    ans = -1    while lo <= hi:        mid = lo + (hi - lo) // 2        if arr[mid] == k:            ans = mid            lo = mid + 1  # Keep searching right for a later occurrence        elif arr[mid] < k:            lo = mid + 1        else:            hi = mid - 1    return ans```### Counting occurrences of $K$Once you have both boundary indices:$$\text{Count}(K) = \begin{cases} \text{last} - \text{first} + 1 & \text{if } \text{first} \ne -1 \\ 0 & \text{if } \text{first} == -1 \end{cases}$$This runs in $\mathcal{O}(\log N)$ time instead of scanning the duplicate block linearly.## 3. Floor and ceil of $K$Given a sorted array and target $K$:* **Floor of $K$:** Largest element $\le K$.* **Ceil of $K$:** Smallest element $\ge K$.```pythondef find_floor(arr: list[int], k: int) -> int:    lo, hi = 0, len(arr) - 1    ans = -1    while lo <= hi:        mid = lo + (hi - lo) // 2        if arr[mid] <= k:            ans = arr[mid]  # Candidate floor; search right for a larger one            lo = mid + 1        else:            hi = mid - 1    return ansdef find_ceil(arr: list[int], k: int) -> int:    lo, hi = 0, len(arr) - 1    ans = -1    while lo <= hi:        mid = lo + (hi - lo) // 2        if arr[mid] >= k:            ans = arr[mid]  # Candidate ceil; search left for a smaller one            hi = mid - 1        else:            lo = mid + 1    return ans```
