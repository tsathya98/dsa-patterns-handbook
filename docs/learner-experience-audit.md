# Learner experience audit

Audited on 21 October 2026. This review covers navigation, page purpose, study order, reading load, and the links between learning and practice.

The separate "Visual curriculum" entry duplicated the AI/ML learning tracks. AI/ML now has one home: choose a track, follow its ordered lessons, and use the applied guides afterward. Existing curriculum bookmarks still work.

## Verification

- HTTP sweep of every collection destination: 564 company pages (561 banks plus three profile-only destinations), 149 reference documents, and 57 Python sources. All 770 returned page content with a heading and no unintended redirects. Individual routes and headings are recorded in [learner-audit-routes.json](learner-audit-routes.json).
- Route checks cover 22 main page/view variants, all four track pages, and all 28 lesson pages. They verify exact headings, track membership, teaching anchors, six blocks, next/connected links, end-of-track behavior, old bookmarks, source assets, and unknown-route 404s.
- Browser walkthroughs cover every main page template and the subject-to-track-to-lesson path. At 390 px, the overview, AI home, track, lesson, DSA, system design, problem list, review queue, company directory/profile, cheat sheets, plan, library, search, playground, focus, and reader had no body-level horizontal overflow. The mobile menu opens, navigates, and closes after a selection.
- Browser interactions verified guide and problem reviews (including concepts shared by multiple exercises), exact problem-number search, saved lessons through an old curriculum URL, reference pagination, and light/dark appearance. Temporary review/bookmark changes were restored; the last AI lesson was returned to the previously visited KV-cache guide.
- Content/catalog checks and TypeScript pass, including 237 problems, the complete 75/150/30 lists, 710 document links, 129 equations, and all 18 Python templates through the actual runtime. Production build passes.

This is an information architecture and usability audit. All collection URLs were checked programmatically; visual inspection covered the shared page templates. It does not claim a new factual review of every original document, a current compensation survey, or learner testing with external participants.
